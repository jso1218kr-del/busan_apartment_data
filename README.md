# 부산 아파트 실거래가 데이터 분석

부산 아파트 실거래가 데이터를 활용하여
데이터 전처리 과정을 학습하고 직접 적용하기 위한 프로젝트

## 프로젝트 목표

원본 데이터를 분석 가능한 형태로 변환하는 과정에서 다음 내용을 학습

-데이터 구조 파악
-결측치 처리
-중복 데이터 처리
-문자열 데이터 정제
-데이터 ㅏ입 변환
-이상치 탐색
-날짜 데이터 처리
-파생변수 생성
-탐색적 데이터 분석

## 진행 과정

-[]데이터 수집
-[]데이터 구조 탐색
-[]결측치 확인 및 처리
-[]중복 데이터 확인 및 처리
-[]문자열 및 자료형 정제
-[]이상치 탐색
-[]파생변수 생성
-[]데이터 분석 및 시각화
