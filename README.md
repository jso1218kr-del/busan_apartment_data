# 부산 아파트 실거래가 데이터 분석

부산 아파트 실거래가 데이터를 활용하여
데이터 전처리 과정을 학습하고 직접 적용하기 위한 프로젝트

## 프로젝트 목표

원본 데이터를 분석 가능한 형태로 변환하는 과정에서 다음 내용을 학습

-데이터 구조 파악 -결측치 처리 -중복 데이터 처리 -문자열 데이터 정제 -데이터 ㅏ입 변환 -이상치 탐색 -날짜 데이터 처리 -파생변수 생성 -탐색적 데이터 분석

## 진행 과정

-[]데이터 수집
-[]데이터 구조 탐색
-[]결측치 확인 및 처리
-[]중복 데이터 확인 및 처리
-[]문자열 및 자료형 정제
-[]이상치 탐색
-[]파생변수 생성
-[]데이터 분석 및 시각화

## 데이터 출처

- 출처: 국토교통부 실거래가 공개시스템
- 데이터: 부산광역시 아파트 매매 실거래가
- 조회 기간: 2025-08-01 ~ 2026-07-31
- 데이터 형식: CSV
- 활용 목적: 데이터 전처리 및 탐색적 데이터 분석 학습

원본 데이터는 `data/raw`에 보관하며,
전처리 과정에서 원본 파일을 직접 수정하지 않습니다.

## 데이터 전처리 과정

국토교통부 아파트 실거래가 원본 데이터를 바로 수정하지 않고,
먼저 데이터 구조와 품질을 탐색한 뒤 처리 기준을 결정했다.

### 1. 원본 데이터 구조 확인

원본 CSV에는 실제 거래 데이터 외에 안내문과 조회 조건이 포함되어 있었다.

- 0~14행: 안내 및 조회 조건
- 15행: 컬럼명
- 16행 이후: 실제 거래 데이터

따라서 `skiprows=15`를 적용하여 실제 거래 데이터만 불러왔다.

### 2. 결측값 의미 분석

원본 데이터에서는 일부 값이 `NaN`이 아닌 `-` 문자열로 표현되어 있었다.

단순히 모든 `-` 값을 삭제하거나 동일하게 처리하지 않고
다른 컬럼과의 관계를 확인하여 의미를 구분했다.

- `해제사유발생일`: 거래가 해제되지 않은 경우
- `등기일자`: 거래 해제 또는 아직 등기 정보가 반영되지 않은 경우
- `중개사소재지`: 직거래는 `해당없음`, 중개거래 1건은 실제 결측값
- `동`: 등기 정보 미반영 또는 동 정보가 제공되지 않는 경우

결측값의 원인을 확인한 후 필요한 값만 `NaN`/`NaT`로 변환했다.

### 3. 중복 데이터 검증

`NO` 컬럼을 제외하고 중복 여부를 확인한 결과
145개의 추가 중복 행이 탐지되었다.

그러나 공개 데이터에는 개별 세대의 호수 정보가 없어
동일 조건의 서로 다른 실제 거래를 완전히 구분할 수 없었다.

따라서 중복 후보를 자동 삭제하지 않고 원본 거래를 유지했다.

### 4. 자료형 변환

분석에 적합하도록 주요 컬럼의 자료형을 정리했다.

- `거래금액(만원)`: 문자열 → 정수형
- `계약년월` + `계약일`: `계약일자` 생성
- `해제사유발생일`: 날짜형 변환
- `등기일자`: 날짜형 변환

특히 `등기일자`는 자동 날짜 변환 시 잘못된 날짜로 해석되는 문제를 발견하여
원본 형식인 `%y.%m.%d`를 명시적으로 적용했다.

### 5. 이상치 탐색

IQR을 이용해 거래금액 이상치 후보를 탐색했다.

부산 전체 기준으로는 1,351건이 탐지되었지만,
해운대구·수영구 등 고가 지역의 정상 거래가 다수 포함되어 있었다.

지역별 IQR을 다시 적용한 결과 1,012건이 탐지되었으며,

- 두 기준 모두 이상치: 641건
- 전체 기준에서만 이상치: 710건
- 지역별 기준에서만 이상치: 371건

으로 나타났다.

이를 통해 부동산 가격은 지역에 따라 가격 수준이 크게 다르므로
단일 통계 기준만으로 이상치를 삭제하는 것은 적절하지 않다고 판단했다.

### 6. 파생변수 생성

이후 분석에 활용할 수 있도록 다음 컬럼을 추가했다.

- `계약일자`
- `구`
- `거래해제여부`
- `전용면적(평)`
- `평당가격(만원)`
- `건물연식`

### 7. 최종 결과

- 원본 데이터: **38,163건 × 20개 컬럼**
- 정제 데이터: **38,163건 × 26개 컬럼**
- 삭제된 거래: **0건**
- 정제 데이터 저장 위치: `data/processed/`

원본 거래정보를 최대한 유지하면서
자료형과 결측값 표현을 정리하고 분석용 파생변수를 생성했다.
